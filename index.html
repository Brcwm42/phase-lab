01 //
PHASE 01: CONTEXT

專案背景 (Project Background)

《RE:SONANCE》是一場落腳於百年前重工業發電廠遺址的國際實驗聲響藝術節。策展主軸旨在探討「後工業噪聲、人體感知頻率與歷史殘響」之共生關係。委託方期盼一套能打破主流展演慣常套路、體現純粹聲響物理質地的識別機制。

KEY CONSTRAINTS
  • 非典型工業空間導引
  • 無形聲音可視化難題
  • 三語系跨國展演需求
02 //
PHASE 02: FRICTION

核心挑戰 (Core Challenge)

聲音本質是無形的時空衰減波。如何將抽象的聲波頻譜轉化為具備「嚴謹數學結構」且能在手機螢幕、實體票券、重型鋼構空間指標中維持一致張力的視覺語言？同時，現場需避免繁複眩目的光害，維持沉浸聆聽本質。

CORE FRICTION

如何避免傳統音樂節浮誇視覺干擾，回歸頻率與空間的本質共鳴。

03 //
PHASE 03: SYNTHESIS

設計策略 (Design Strategy)

我們以「音波共振拓撲 (Resonant Topology)」為核心演算法，將參展藝術家的音檔 FFT 數據直接轉譯為動態幾何座標。建立「生成式點陣系統」，所有標誌與輔助幾何元素皆能根據環境現場分貝產生即時波動。

METHOD A: DATA MAPPING 聲音實時音頻頻譜 FFT ➔ 幾何網格碎形
METHOD B: LOW-LUMEN WAYFINDING 冷調反光油墨與低照度紅外線導光標識
04 //
PHASE 04: DELIVERED

最終成果 (Final Outcome)

展期四天吸引逾 18,000 名跨國訪客，生成式識別系統被海外設計媒體《Frame》與《It’s Nice That》專題報導。現場動態導引降低迷航率 84%，並榮獲金點設計獎年度最佳設計入圍。
